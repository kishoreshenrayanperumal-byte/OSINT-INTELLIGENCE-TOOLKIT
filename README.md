# OSINT Intelligence Toolkit

A Python-based OSINT toolkit for domain reconnaissance and information gathering.

## Features
- WHOIS Lookup
- DNS Lookup
- IP Lookup
- SSL Certificate Information
- HTTP Headers Analysis
- Technology Detection
- Robots.txt Analysis
- Reverse DNS Lookup
- GeoIP Lookup
- Subdomain Enumeration
- Email Security (SPF, DKIM, DMARC)
- Port Scanning

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python app.py
```

Enter a domain name when prompted.
